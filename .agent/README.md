# Agent Resources

This directory contains resources for AI agents working with Resolvio.

## Skills

- **[resolvio](./skills/resolvio/SKILL.md)** - Comprehensive skill for interacting with the Resolvio API

## Using the Resolvio Skill

The Resolvio skill teaches agents how to:
- Resolve ENS names to addresses
- Perform reverse lookups (address → name)
- Fetch ENS profiles and text records
- Handle multi-chain address resolution

Simply read the skill file to understand how to use the Resolvio API:

```bash
view_file .agent/skills/resolvio/SKILL.md
```
